# Contributing

Thanks for helping improve this portfolio project.

1. Open an issue describing the problem or proposed change.
2. Create a focused branch from `main`.
3. Follow the setup and verification commands in the README.
4. Add or update tests for behavioral changes.
5. Open a pull request explaining the user impact, verification performed, and any GxP/CSV boundary affected.

Never contribute proprietary, personal, patient, employer, production, or regulated data. Use synthetic examples only. Security vulnerabilities should be reported through the process in `SECURITY.md`, not a public issue.
